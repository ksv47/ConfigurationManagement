## Анонс (заголовок и краткое описание)

**Управление конфигурациями 1С** — бесплатное кроссплатформенное десктоп-приложение
с открытым исходным кодом, которое заменяет стандартный список баз 1С и даёт удобный
современный интерфейс для ежедневной работы с информационными базами платформы
1С:Предприятие 8.3.

Одна кодовая база работает и на **Windows** (WPF), и на **Linux** (Avalonia 11).
Приложение решает повседневные задачи разработчика и администратора 1С: запуск баз
в «1С:Предприятие» и «Конфигуратор», удобные группы и поиск, избранное с горячими
клавишами, очистка кэша по GUID, синхронизация со стандартным файлом `ibases.v8i`,
создание баз, выгрузка `.dt`/`.cf`, учётные записи (профили) и многое другое.

---

## Что это такое

**«Управление конфигурациями 1С»** — это десктопная программа на платформе **.NET 10**
(**WPF** на Windows и **Avalonia 11** на Linux), созданная как полноценная замена
стандартного списка баз 1С. Проект собирается из одной кодовой базы под обе операционные
системы (`net10.0-windows` для WPF на Windows и `net10.0` для Avalonia на Linux) и
распространяется бесплатно с **открытым исходным кодом**.

Программа ориентирована на разработчиков, администраторов и пользователей 1С,
которым не хватает возможностей штатного стартера: устаревший интерфейс, отсутствие
удобного поиска по списку баз, невозможность быстро запускать базу в нужном режиме
и разрядности, чистка кэша «вручную» по каталогам, сложная работа с несколькими
учётными записями.

## Основные возможности

### 🚀 Запуск информационных баз
- Запуск базы в режимах **«1С:Предприятие»** и **«Конфигуратор»**.
- Свободно назначаемые **горячие клавиши** (Настройки → Клавиши): `Ctrl`, `Shift`, `Alt`,
  `Win`, F2–F12, Delete, Insert. По умолчанию — `F3` (Предприятие) / `F4` (Конфигуратор).
- **Горячие клавиши избранного** `Alt+1…Alt+9` — быстрый запуск любимых баз.
- Выбор типа клиента: **тонкий / толстый / веб-клиент**, толстый клиент разделён по режимам форм
  (управляемые / обычные).
- **Разрядность запуска** по документации 1С: приоритет 32 / приоритет 64 / только 32 / только 64,
  а также глобальная «Разрядность по умолчанию».
- Автопоиск установленной платформы 1С и запуск **конкретной версии**, в том числе **неполной**
  (`8.3`, `8.3.27`) — подбирается новейшая установленная сборка.
- Окно выбора версии платформы «как в стартере 1С» с деревом и подсветкой текущей версии.
- **«Перейти по ссылке»** — запуск базы по ссылке `e1c://…`, `server\База`, `http(s)://…`.
- Конфигуратор параметров запуска: поле ввода + справочник ключей 1С с двойным кликом.
- Действие после запуска: свернуть в трей или закрыть программу.

### 👥 Учётные записи (профили)
- Несколько учётных записей в одном приложении с собственными базами, группами и настройками.
- Окно входа «как в 1С», пароль профиля хранится безопасно (**PBKDF2-SHA256** со случайной солью).
- Плавная миграция данных при обновлении.

### 🗂️ Управление списком баз
- Вкладки **Все базы / Избранное / Недавние**.
- Иерархические группы (группа в группе) с цветами и иконками.
- Настраиваемые **колонки**: наименование, версия платформы (с суффиксом `[x86]/[x64]`),
  режим запуска, сервер/база, последний запуск, размер.
- Цветные иконки статуса: папка (файловая), глобус (веб-сервер), сеть (клиент-сервер),
  красный крест (недоступна). Кнопка «Доступность» для массовой проверки.
- **Поиск** с debounce и **мультифильтр по тегам** с облаком тегов.
- Избранное (★) и закрепление (📌), перетаскивание баз и групп, навигация стрелками.

### 🏷️ Группы
- Вложенные группы с наглядным смещением, цветом и иконкой.
- Сортировка групп по имени (А→Я / Я→А), сворачивание/разворачивание всех групп.
- Служебные узлы «Закреплённые» и «Без группы» с собственным оформлением.

### 🔄 Импорт, экспорт и синхронизация
- Импорт / экспорт стандартного файла **`ibases.v8i`**.
- **Синхронизация** с `ibases.v8i`: только загрузка / только выгрузка / двусторонняя;
  триггеры — при старте, по интервалу, по расписанию.
- Экспорт / импорт списка в JSON, резервные копии `ibases.v8i`.

### 🧹 Очистка кэша 1С
- Очистка кэша выбранной базы по **GUID** (программный и/или пользовательский).
- Показ текущего размера кэша для каждой базы и **«остатков» от удалённых баз**.
- Закреплённая шапка колонок, изменяемые ширины, split-кнопка в правой панели.

### 🛠️ Создание информационных баз
- Создание через `CREATEINFOBASE`: пустая база или **из шаблона** (`.cf` / `.dt`).
- Файловые и клиент-серверные базы с параметрами СУБД.
- Надёжное экранирование значений подключения (по правилу 1С) и защита от внедрения ключа `1cv8`.
- Предупреждение о несоответствии версии платформы при создании клиент-серверной базы.

### 📦 Обслуживание баз
- История запусков (до 30 записей), выгрузка `.dt` / `.cf`, тестирование ИБ.
- Анимированный индикатор выгрузки со сводкой при наведении.
- Дата-время в имени файла выгрузки с настраиваемым шаблоном.
- Открыть каталог базы, ярлык на рабочем столе, завершение процессов 1С, удаление базы
  с физическим удалением каталога.

### 💾 Резервное копирование и восстановление профиля
- Сохранение всех настроек, списка баз и `ibases.v8i` одной кнопкой и восстановление
  после переустановки системы, в том числе автоматически при запуске.

### 🪟 Системный трей и поведение
- Значок в трее, закрытие в трей, контекстное меню с недавними базами.
- Запрет второго экземпляра, `Esc` → трей, запоминание положения окна и монитора.

### 🌍 Локализация
- **Русский** и **английский** из коробки, автоопределение языка ОС.
- Загрузка дополнительных языков без пересборки (файлы `*.json`).

### 🎨 Интерфейс
- **Светлая** и **тёмная** темы, полноценный редактор цветовых схем
  (Настройки → Цветовое оформление) с живым предпросмотром и экспортом/импортом в JSON.
- **Компактный режим**, настройка шрифта по областям интерфейса.
- Единый стиль Material Design: окна сообщений, «?»-подсказки, иконки команд.
- Нижняя панель-статус с путём, портом, платформой, разрядностью и пользователем.

### ⚙️ Настройки приложения
- Вкладки: Платформы, Отображение, Клавиши, Настройки, ibases.v8i, Базы, О программе.
- Вкладка «Отображение»: значки и кнопки, колонки списка, панели, нижняя панель.
- Вкладка «Базы»: каталоги шаблонов, экспорт/загрузка списка, обслуживание.
- Окно настроек подключения базы с вертикальными вкладками
  (База / Подключение / Хранилище / Авторизация / Запуск / Разрядность / Платформа / Идентификатор)
  и кнопкой «Вставить строку подключения».

## Требования

### Windows
- **Windows 10 / 11**
- Установленная платформа **1С:Предприятие 8.3** (для запуска баз)
- Для сборки из исходного кода — **.NET 10 SDK**

### Linux
- Установленная платформа **1С:Предприятие 8.3 для Linux** (клиент `1cv8`)
- Зависимости пакета: GTK3, glib2, `xdg-utils`
- Для трея на GNOME Shell может потребоваться расширение **AppIndicator**

## Установка

### Windows
Готовый self-contained **single-file** исполняемый файл `ConfigurationManagement.exe`
не требует установки .NET Runtime на целевой машине. Запустите его и пользуйтесь.

### Linux
Доступны готовые пакеты:
- **AppImage** — переносимый файл `ConfigurationManagement-x86_64.AppImage`;
- **`.deb`** — для Ubuntu/Debian/Astra (`configuration-management_<версия>_amd64.deb`, установка через `sudo dpkg -i …`);
- структура `.rpm` (ALT Linux) и `snap` поддержана на уровне пакета.

Сборка из исходного кода (Linux):
```bash
./build.sh                     # только сборка (Avalonia, net10.0)
./build.sh Release publish     # сборка + self-contained single-file linux-x64
```
