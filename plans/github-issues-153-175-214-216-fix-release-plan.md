### #216 → 0.3.7.5 — центрирование текста в поле «Размер» шрифта
Пользователь сообщает, что текст в поле размера шрифта уходит вниз (вертикально не отцентрован), исправление 0.3.6.97 не помогло.
- Проверить вертикальное выравнивание поля (TextBox) в [`Views/SettingsWindow.xaml`](../Configuration%20Management/Views/SettingsWindow.xaml) (WPF) и [`Views/SettingsWindow.Avalonia.cs`](../Configuration%20Management/Views/SettingsWindow.Avalonia.cs) (Linux).
- Настроить отступы/высоту/`VerticalContentAlignment` так, чтобы текст был отцентрован по вертикали в обеих сборках.
- Собрать обе цели (WPF `net10.0-windows`, Linux `-p:ForceLinux=true`), проверить без ошибок.

### #214 → 0.3.7.6 — компактный режим: горизонтальное смещение иконок после запуска
- Симптом: сразу после запуска при включённом компактном режиме иконки списка уезжают влево; корректно выравниваются только после двойного переключения тумблера. Регрессия появилась в 0.3.6.96/97.
- Локализовать расчёт горизонтальных отступов компактного режима в [`Themes/ThemeManager.cs`](../Configuration%20Management/Themes/ThemeManager.cs) и связанном коде строк списка (`LeveledTreeView*`).
- Причина, вероятно, в порядке применения темы/компактности до первой отрисовки; добиться, чтобы состояние применялось при старте без повторного переключения.
- Проверить обе сборки.

### #175 → 0.3.7.7 — доработка шаблона имени COM-коннектора
Последние комментарии `7OH` (09-09 18:58–19:00):
1. **Показывать, какой COM-коннектор реально использовался** — в логах и на форме (например, свойства базы), т.к. сейчас не видно нигде.
2. **Вариант со скобками**: шаблон вида `V%V12%(вася_%V3%)(пупкин_%V4%)` — если переменная отсутствует, удалять её вместе с парой скобок (и разделителями). Если сегмент присутствует — скобки всё равно убирать.
3. **Поведение при пустом шаблоне** — предпросмотр показывает «—»; убедиться, что в работе подставляется дефолтный список `KnownProgIds` (как описано в 0.3.6.72).
- Логика разворота — общий [`Services/ComConnectorTemplate.cs`](../Configuration%20Management/Services/ComConnectorTemplate.cs); доработать обрезку и поддержку скобок там же, единообразно для подключения и предпросмотра.
- Вывод используемого ProgID: логировать в `OneCComConnector`/агентском процессе и показывать на форме (при наличии места — предпросмотр, а также в журнале подключения).
- Проверить обе сборки.

### #153 → 0.3.7.8 — Linux/виртуалка: окно закрывается через несколько секунд

Кандидаты: потеря фокуса/деактивация окна, обработка закрытия, одиночный экземпляр, таймер, исключение в фоновой задаче, пойманное общим обработчиком (проверить `errors.log`), либо вклад рендера.
