Здравствуйте! Исправлено в версии **0.3.7.11**.

### Что исправлено
Клавиша Esc на Linux больше не закрывает всё приложение, а закрывает только активный диалог. Обработка Esc в главном окне теперь проверяет, открыт ли какой-либо модальный диалог (свойства базы, настройки), через новый метод `HasOpenModalDialog()`. Если диалог открыт — Esc закрывает его, а главное окно остаётся живым; закрытие приложения по Esc возможно только когда нет открытых модальных окон.

Правка только в Linux/Avalonia-сборке; Windows/WPF не затрагивается.

Подробнее — раздел [CHANGELOG 0.3.7.11](https://github.com/sivatorov/ConfigurationManagement/blob/main/CHANGELOG.md#03711---2026-09-10). Прошу проверить.
