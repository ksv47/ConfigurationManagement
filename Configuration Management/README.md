# Управление конфигурациями 1С

![Версия](https://img.shields.io/badge/Версия-0.3.5.12-1F6FEB) ![.NET](https://img.shields.io/badge/.NET-10-512BD4) ![WPF](https://img.shields.io/badge/WPF-4B8BBE) ![Лицензия](https://img.shields.io/badge/Лицензия-Open%20Source-success)

> Десктопное приложение для управления информационными базами 1С:Предприятие 8.3. **Версия 0.3.5.12**

**Управление конфигурациями 1С** — это настольное приложение на платформе **.NET (WPF)**, которое заменяет стандартный список баз 1С и предоставляет современный интерфейс для работы с информационными базами: запуск в режимах «1С:Предприятие» и «Конфигуратор», вкладки **Все базы / Избранное / Недавние**, иерархические группы, избранное с `Alt+1…9`, мультифильтр по тегам, очистка кеша, синхронизация с `ibases.v8i`, системный трей, светлая и тёмная темы.

## ✨ Возможности

### 🚀 Запуск информационных баз
- Запуск базы в режиме **«1С:Предприятие»** и **«Конфигуратор»**.
- **Свободно назначаемые горячие клавиши** действий (по умолчанию `F3` / `F4`) — как в конфигураторе 1С: в **Настройки → Клавиши** достаточно установить курсор в поле и нажать сочетание (поддерживаются **Ctrl, Shift, Alt, Win**), отображаются на кнопках правой панели и в контекстном меню.
- **Горячие клавиши вкладок списка** — отдельные комбинации для переключения **Все базы / Избранное / Недавние** (задаются в **Настройки → Клавиши**).
- **Горячие клавиши избранного** — `Alt+1`…`Alt+9`: при добавлении в избранное назначается свободный слот; порядок слотов настраивается в окне настроек.
- Выбор типа клиента: **тонкий** / **толстый**, разрядности **32 / 64**, режим **веб-клиента**.
- Автопоиск установленной платформы 1С (лаунчер `1CEStart.exe` или `1cv8.exe` / `1cv8c.exe`).
- Запуск **конкретной версии** платформы, заданной для базы.
- **Конфигуратор параметров запуска** — визуальный выбор ключей командной строки (`/UC`, `/DisableStartupMessages`, `/Debug` и др.).
- **Окно выбора версии платформы** ([`Views/PlatformVersionPickerWindow.xaml`](Views/PlatformVersionPickerWindow.xaml)): радиокнопки фильтра разрядности («Все / x32 / x64») выполнены в стиле **Material Design** — округлый индикатор с акцентной заливкой при выборе, мягкая подложка и акцентная обводка при наведении.
- **Единый стиль Material Design** для элементов управления и диалогов: радиокнопки/чекбоксы в окне подключения (вкладка «Авторизация») и других окнах; блок «Остатки от удалённых баз» в очистке кеша больше не обрезается — чекбокс занимает всю доступную ширину нижней панели (колонка `*`), подпись переносится на несколько строк (`TextWrapping=Wrap`) и читается целиком даже при минимальной ширине окна, справа остаются размер и кнопки «Очистить»/«Отмена» ([`Views/CacheCleanWindow.xaml`](Views/CacheCleanWindow.xaml)); у служебного узла «Закреплённые» появилась кнопка «Изменить группу» (правка цвета и иконки); кнопка «Изменить группу» в панели группы больше не подсвечивается при наведении/фокусе (стиль `IconButton`, как у соседней «Удалить»); все всплывающие предупреждения/подтверждения/ошибки показываются собственным окном сообщений ([`Services/MaterialMessageWindow.xaml`](Services/MaterialMessageWindow.xaml)) — в диалоге подтверждения кнопки расположены по порядку «Да» слева / «Нет» справа, текст кнопки подтверждения («Да»/«ОК») сделан контрастным белым жирным на зелёном фоне, а закрытие окна выполняется надёжно без падения `InvalidOperationException` для `DialogResult`.

### 🗂️ Управление списком баз
- **Вкладки фильтра**: **Все базы**, **Избранное**, **Недавние** (по дате последнего запуска).
- Иерархический список с группами, закреплёнными базами и узлом «Без группы».
- Колонки: наименование, версия платформы, режим запуска, сервер/база, последний запуск; видимость колонок настраивается. При вложенных группах **колонки данных выровнены с заголовками**; сдвигается только блок ★ / 📌 / название (под иконкой родительской группы).
- **Сортировка по клику** на заголовки колонок (название, дата и др.).
- Добавление, редактирование и удаление баз; мастер «Что добавить?» (база или группа).
- **Избранное** (★) и **закрепление** (📌) в одном блоке с названием; закреплённые — в отдельной группе сверху.
- **Поиск** по имени, описанию, группе, версии и тегам (с debounce, без «тормозов» на каждый символ).
- **Теги**: инлайн-добавление в строке базы, компактные чипы, удаление крестиком, **мультифильтр** (несколько тегов сразу) и облако тегов на панели отбора. При **отключении показа тегов** (верхняя кнопка «Показывать теги») выбранные теги **фильтра списка баз** автоматически **сбрасываются**.
- Во вкладках **«Избранное»** и **«Недавние»**, при **отборе по тегу** и при **поиске** группы и закреплённые базы **временно скрываются** — показывается единый плоский список найденных баз, что исключает дубли (закреплённая база раньше попадала и в «Закреплённые», и в свою группу). При возврате к вкладке «Все базы» дерево групп и закрепления восстанавливаются.
- Перетаскивание баз и групп; сворачивание/разворачивание всех групп с верхней панели.

### 🏷️ Группы
- Вложенные группы («группа в группе») с наглядным смещением по глубине; названия баз с ★/📌 — под иконкой папки группы; колонки данных не смещаются. Цвет и **иконка** группы.
- В правой панели при выборе группы отображается **выбранная иконка**.
- Создание, редактирование, удаление; выбор родителя в дереве групп или **без родителя** (корневая); цвет и иконка группы.
- Окно группы разделено на **горизонтальные вкладки** «Основные / Цвет / Иконка» по аналогии с окном настроек; кнопки «Сохранить»/«Отмена» всегда закреплены внизу (зелёная «Сохранить», «Отмена» с красной обводкой).
- **Группы без названия** (например, импортированные из `ibases.v8i`) можно создавать и редактировать; в дереве такие группы отображаются как «Без названия».
- **Пустые группы** (без баз) отображаются в дереве в правильной иерархии — внутри своей родительской группы. Переключатель рядом с «показывать группы» на верхней панели и в **Настройки → Отображение → Панели**.
- Служебные узлы **«Закреплённые»** и **«Без группы»** имеют собственное оформление по умолчанию, отличающееся от обычных групп: закреплённые — фиолетовый цвет, «Без группы» — серый. Кнопка **«Удалить группу»** у них скрыта. Оформление обоих узлов меняется через **«Изменить группу»** (кнопка в строке узла или горячая клавиша правки) — открывается то же окно (вкладки **Основные / Цвет / Иконка**), но поля **«Наименование»** и **«Родительская группа»** заблокированы. Изменения сохраняются в настройках приложения.

### 🔄 Импорт, экспорт и синхронизация
- Импорт / экспорт **`ibases.v8i`** (в т.ч. кнопки на главном окне).
- **Синхронизация** с `ibases.v8i`: отключена / только загрузка / только выгрузка / двусторонняя; триггеры — при старте, по интервалу, по расписанию.
- Экспорт / импорт списка в **JSON**; очистка всего списка с подтверждением.
- Автосопоставление **ID (GUID)** базы из `ibases.v8i` для точечной очистки кеша.

### 🧹 Очистка кеша 1С
- **Раздельная очистка** **программного** (`%LOCALAPPDATA%\1C\1cv8…`) и **пользовательского** (`%APPDATA%\1C\1cv8…`) кеша — это разные данные, по-разному влияющие на информационные базы. Кнопка «Очистить кэш» в правой панели и контекстное меню базы открывают **выпадающее меню** с выбором типа кеша (включая очистку **обоих одновременно**).
- Окно **«Очистка кэша 1С»** позволяет выбрать тип кеша и **набор баз** для точечной очистки по GUID: **«Выбрать все»** и **«Снять все»** (единый стиль), а также **поле поиска базы** по имени/строке подключения. Чекбоксы выполнены в стиле **Material Design** (цветная заливка, галочка/тире, подсветка при наведении).

### 🪟 Системный трей и поведение

- Запрет второго экземпляра (опционально) с активацией уже открытого окна.
- Контекстное меню трея (показать / выход).

## 🔗 Работа с файлом `ibases.v8i`

Приложение взаимодействует со стандартным файлом списка баз 1С `ibases.v8i` (расположен в `%APPDATA%\1C\1CEStart\`):

- **Импорт** — считывает базы, группы, ID (GUID), версию платформы (`Version`), режим запуска (`App`), локаль (`Locale`), признак внешней базы (`External`), скорость соединения (`ClientConnectionSpeed`), признак веб-клиента (`WA`) и дополнительные параметры подключения (`AdditionalParameters`, сохраняются в параметры запуска базы). Поддерживает **иерархию групп**: пути вида «Родитель\Дочерняя» разбираются на сегменты, недостающие родительские группы создаются автоматически. Добавляет новые базы и обновляет существующие.
- **Экспорт** — выгружает базы и группы приложения в файл `ibases.v8i`, добавляя новые записи и обновляя существующие (по совпадению имени базы). Группы записываются секциями без строки подключения, для баз переносятся версия платформы, режим запуска (`App`/`DefaultApp`) и дополнительные параметры запуска. Существующие секции-группы только обновляются (новые при выгрузке не создаются), а дубликаты секций с одинаковым именем устраняются (приоритет — за базой).
- **Синхронизация** — в окне настроек можно задать режим автоматической синхронизации с файлом `ibases.v8i` (отключена / только загрузка / только выгрузка / двусторонняя) и путь к файлу. Синхронизация выполняется автоматически при изменении списка баз, при запуске приложения, через заданный интервал или по расписанию, а также вручную по кнопкам «Загрузить» / «Выгрузить».
- **Сопоставление ID** — при ручном создании базы приложение автоматически находит её ID в `ibases.v8i` по имени или строке подключения и подставляет его. Это обеспечивает корректную точечную очистку кеша 1С по GUID.
- **Очистка кеша** — использует ID базы (GUID) для удаления только соответствующего подкаталога кеша, а не всего каталога базы. Очистка **программного** и **пользовательского** кеша выполняется раздельно (или одновременно) через выпадающее меню; в диалоге можно выбрать **набор баз** или **все базы** сразу.

## 🧩 Архитектура

Приложение построено по паттерну **MVVM**:

- **Models** — описывают доменные сущности (информационные базы, группы, настройки подключения).
- **ViewModels** — содержат логику представления и команды, реализуют `INotifyPropertyChanged`.
- **Views (XAML)** — отвечают за отображение и привязку данных.
- **Services** — инкапсулируют работу с платформой 1С, файловой системой и хранилищем данных.

## Сборка

### Локально (Windows)

```powershell
# Только сборка
.\build.ps1

# Сборка + публикация single-file win-x64
.\build.ps1 -Publish
```

Результат публикации: `publish\win-x64\`.

Или вручную:

```powershell
dotnet build "Configuration Management.csproj" -c Release
dotnet publish "Configuration Management.csproj" -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\publish\win-x64
```

### Автоматическая сборка (GitHub Actions)

| Workflow | Когда запускается | Что делает |
|----------|-------------------|------------|
| **Build** (`.github/workflows/build.yml`) | push / PR в `main`, `master`, `develop` | Restore → Build Debug/Release → Publish win-x64 → artifact |
| **Release** (`.github/workflows/release.yml`) | тег `v*.*.*` или ручной запуск | Publish + ZIP + GitHub Release |

Создание релиза:

```bash
git tag v2.5.14
git push origin v2.2.1
```

Артефакт `ConfigurationManagement-v2.5.14-win-x64.zip` появится в Releases.

> Требуется Windows-раннер (`windows-latest`): проект WPF (`net10.0-windows`).
