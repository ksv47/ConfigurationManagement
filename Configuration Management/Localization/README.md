# Локализация

Приложение поддерживает несколько языков интерфейса.

## Как это работает

* Встроенные языки **русский** (`ru`) и **английский** (`en`) хранятся в
  [`Languages/ru.json`](Languages/ru.json) и [`Languages/en.json`](Languages/en.json)
  и встраиваются в сборку.
* При запуске выбирается язык:
  1. сохранённый в настройках (`AppSettings.Language`);
  2. если его нет — язык операционной системы (если он есть среди доступных);
  3. иначе — русский.
* Язык можно сменить в окне «Настройки» (вкладка «Отображение»/«Цветовое
  оформление» на Windows, вкладка «Настройки» на Linux). Выбранный язык
  применяется сразу и сохраняется.
* Смена языка **применяется мгновенно к открытым окнам**:
  * на Windows (WPF) тексты связаны через `{loc:Loc ...}` и обновляются
    автоматически через `Source.NotifyAll()`;
  * на Linux (Avalonia) главное окно подписывается на событие
    `LocalizationManager.Instance.LanguageChanged` и пересобирает своё
    содержимое, поэтому названия колонок, кнопки правой панели и подсказки
    обновляются сразу; остальные диалоговые окна (наследники `ModalWindowBase`)
    тоже реагируют на `LanguageChanged`.

## Добавление нового языка (без пересборки)

Создайте файл `*.json` в папке `Languages` рядом с исполняемым файлом
или в каталоге данных приложения:

* Windows: рядом с `ConfigurationManagement.exe`
* Linux: рядом с исполняемым файлом или в
  `~/.config/ConfigurationManagement/Languages`

Формат файла (см. [en.json](Languages/en.json) как образец):

```json
{
  "code": "de",
  "name": "Deutsch",
  "strings": {
    "App.Title": "Verwaltung von 1C-Konfigurationen",
    "Main.Add": "Hinzufügen"
  }
}
```

После добавления файла язык появляется в списке выбора в настройках.

## Как добавить перевод строки

1. Откройте [`ru.json`](Languages/ru.json) — он является источником ключей.
2. Добавьте новый ключ `"Область.Ключ": "Русский текст"`.
3. Добавьте тот же ключ с переводом в `en.json` и другие языковые файлы.

Если для текущего языка ключ отсутствует, выполняется откат (fallback):
**английский → русский → сам ключ**. Поэтому приложение не «ломается», даже если
часть строк ещё не переведена.

## Механизм в коде

* `LocalizationManager.T("Key")` — перевод строки из кода
  (код-бихайнды, окна, построенные в коде, сообщения).
* `{Binding Loc[Key]}` — перевод через привязку XAML (WPF и Avalonia).
  Источник `Loc` доступен на любой ViewModel (наследуется от `ViewModelBase`)
  или на окне. При смене языка окна с такими привязками обновляются автоматически.
* `LocalizationManager.Instance.AvailableLanguages` — список доступных языков
  (встроенные + внешние).

## Перенос нелокализованных окон

Полностью локализовано главное окно (обе платформы) и окно настроек (выбор языка).
Для остальных окон применяется один и тот же паттерн:

* в коде: заменить строковые литералы на `LocalizationManager.T("Key")`;
* в XAML: заменить `Content="Текст"`/`Header="Текст"` на `Content="{Binding Loc[Key]}"`,
  а `Title="..."` — на `Title="{Binding Loc[Key]}"`, добавив ключи в JSON-файлы.

Заголовки окон удобно локализовать в коде-бихайнде через `LocalizationManager.T(...)`.
