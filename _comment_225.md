Исправлено в версии **0.3.7.10**. При установке через пакет (deb в `/usr/bin`) или запуске из AppImage, когда исполняемый файл нельзя заменить без прав, вместо бесполезного сообщения с текстовым адресом теперь показывается понятный диалог с кликабельной ссылкой «Открыть страницу выпуска» — можно сразу перейти на GitHub и скачать новую версию. Если браузер не открылся, адрес копируется в буфер обмена. Диалог с помощником установки сохранён для случая, когда файл можно заменить без прав. Подробнее — раздел CHANGELOG [0.3.7.10](https://github.com/sivatorov/ConfigurationManagement/blob/main/CHANGELOG.md#03710---2026-09-10).
