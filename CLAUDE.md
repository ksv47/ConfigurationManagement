# Контекст для агента

Форк `sivatorov/ConfigurationManagement`: десктопное приложение управления
информационными базами 1С на .NET 10, WPF под Windows и Avalonia 11 под Linux.

Прежде чем что-то делать, прочитай `PORT-LINUX-STATUS.md` в корне. Там состояние
работы, доказательства по поводу неработающей Linux-ветки апстрима, список
оставшихся ошибок по группам и команды сборки.

## Правила этой папки

* Работаем в ветке `linux-port`. `main` держим чистым апстримом, чтобы `git pull`
  от автора шёл без конфликтов.
* Артефакты сборки и логи держим здесь же, в `_port/`. Наружу ничего не выносим.
* `origin` смотрит на апстрим и доступен только на чтение. Наши правки уходят
  в форк, апстрим не трогаем.
* Ветка `linux-fixes` собирается для отправки автору апстрима: в ней только
  правки исходников, без этого файла и без `PORT-LINUX-STATUS.md`.
* Пушить ветки поимённо. `git push --all` и `--mirror` не использовать:
  в репозитории есть локальные ветки с историей, которой наружу делать нечего.
* Длинное тире в текстах не используем.
* Правки апстримного кода делаем минимальными и по существу, без попутного
  причёсывания чужого стиля: чем меньше дифф, тем проще будет мержить обновления автора.

## Что уже проверено, повторять не нужно

* .NET SDK 10.0.111 стоит системно, `dotnet restore` проходит, Avalonia 11.3.20 тянется.
* WPF-цель `net10.0-windows` на Linux не собирается и не может: нужна Windows-машина.
* Счётчик ошибок компилятора занижен, пока есть ошибки в объявлениях: Roslyn не доходит
  до тел методов. Ориентироваться на него как на меру работы нельзя.
