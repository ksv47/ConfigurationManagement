# 0.3.7.32

Выпуск продолжает доработку issue #236 «Определение конфигураций всех баз» по пожеланиям пользователя: диалог «Определить/обновить конфигурации всех баз» стал информативнее и управляемее.

## Добавлено / исправлено

- **Окно прогресса**: показывается база, которую обновляют сейчас, и результат обработки предыдущей (чтобы успевать прочитать текст ошибки).
- **Опция «Действие при ошибке»**: «Остановить обработку» (по умолчанию) или «Продолжить дальше»; об ошибках пользователь информируется в любом случае — текст ошибки остаётся видимым в строке состояния.
- **Исправлен флажок**: галочка снимается/ставится с первого клика, без предварительного фокуса.
- **Колонка «Платформа»**: отображает заданную для базы версию платформы; строки без платформы автоматически не отмечаются.
- **Индикатор логина/пароля** (зелёная/красная точка) и **кнопка вызова свойств базы** под курсором, которая открывает настройки, не закрывая список; строки без заполненных логина/пароля автоматически не отмечаются.
- **Кнопка «Прекратить»** для остановки фоновой последовательной обработки (через `CancellationToken`).

Реализовано в общей кодовой базе и проверено обеими сборками — Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) — без ошибок.
