# 0.3.6.91

Исправление трёх мелких issues интерфейса: согласование счётчика «Избранного» (#194), затемнение иконок недоступных кнопок панели команд (#197) и стабилизация отступов/компактности главного окна при открытии настроек (#199).

## Исправлено

- **Счётчик «Избранного» согласован между вкладкой, счётчиком и хоткеями** (#194): слоты Alt+1…9 соответствуют только текущим избранным базам. `ViewModels/MainViewModel.Commands.cs` и `ViewModels/MainViewModel.Avalonia.cs` (`SyncFavoriteHotkeys`) больше не хранят ключи баз, которые есть в списке, но не являются избранными. После правки базы через диалог подключения WPF-версия тоже вызывает `SyncFavoriteHotkeys`, чтобы снятие/установка звезды не оставляла расхождения.
- **Недоступные кнопки панели затемняются сразу, как в контекстном меню** (#197): у стиля `IconButton` добавлен триггер недоступности (`IsEnabled=false` → `Opacity 0.4`) в `Themes/LightTheme.xaml`, `Themes/DarkTheme.xaml` и `Themes/Controls.axaml`. Раньше кнопки панели команд гасились только по наведению; теперь состояние видно сразу.
- **Отступы/компактность стабильны при открытии настроек** (#199): в WPF-версии `SettingsWindow.Display.cs` при установке значения переключателя компактного режима подавляет событие `Checked`/`Unchecked`, а `Views/SettingsWindow.xaml.cs` (`OnCompactMode_Toggled`) не вызывает `ApplyCompactMode` на этапе инициализации — «прыжок» отступов исчезает, компактный вид стабилен.

## Файлы

- `ViewModels/MainViewModel.Commands.cs` — `SyncFavoriteHotkeys`: удаление ключей не-избранных баз; вызов `SyncFavoriteHotkeys` после правки через диалог подключения (issue #194).
- `ViewModels/MainViewModel.Avalonia.cs` — `SyncFavoriteHotkeys`: то же удаление ключей не-избранных баз (issue #194).
- `Themes/LightTheme.xaml`, `Themes/DarkTheme.xaml`, `Themes/Controls.axaml` — стиль `IconButton`: триггер недоступности `IsEnabled=false` → `Opacity 0.4` (issue #197).
- `Views/SettingsWindow.xaml.cs` — поле `_suppressCompactEvent` и его проверка в `OnCompactMode_Toggled` (issue #199).
- `Views/SettingsWindow.Display.cs` — подавление события при установке значения переключателя компактного режима (issue #199).
- `Configuration Management.csproj` — версия `0.3.6.90` → `0.3.6.91` (4 поля).
- `CHANGELOG.md`, `README.md` — запись о выпуске и бейдж версии.
