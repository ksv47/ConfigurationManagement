# 0.3.7.35

Выпуск добавляет функционал «Поиск потерянных и забытых баз 1С 8 на дисках» (issue #247): диалог в Настройки → Базы → Список информационных баз позволяет выбрать диски/корни поиска, в фоне отсканировать их в поисках файловых баз 1С (`1Cv8.1CD`) с кнопкой «Прекратить», увидеть найденные базы таблицей и одной кнопкой добавить отсутствующие в списке приложения базы.

## Добавлено

- **Сервис сканирования** [`Services/InfobaseDiskScanner.cs`](Configuration%20Management/Services/InfobaseDiskScanner.cs):
  - перечисление корней поиска — Windows: готовые логические диски (`Environment.GetLogicalDrives` + `DriveInfo.IsReady`); Linux: реальные точки монтирования из `/proc/mounts` без виртуальных/сетевых файловых систем;
  - рекурсивный поиск файлов `1Cv8.1CD` с обработкой отказов доступа (пропуск с подсчётом), отменой через `CancellationToken`, обратным вызовом прогресса и дедупликацией по нормализованному пути.
- **Модель и строка диалога**: [`Models/FoundFileBase.cs`](Configuration%20Management/Models/FoundFileBase.cs) (каталог базы, путь к `1Cv8.1CD`, размер, дата изменения) и [`ViewModels/FoundBaseRowViewModel.cs`](Configuration%20Management/ViewModels/FoundBaseRowViewModel.cs) (флажок выбора, признаки «В приложении» / «В ibases.v8i», отображаемые имя/путь/размер/дата).
- **Диалог** [`Views/FindLostBasesWindow.xaml(.cs)`](Configuration%20Management/Views/FindLostBasesWindow.xaml.cs) / [`Views/FindLostBasesWindow.Avalonia.cs`](Configuration%20Management/Views/FindLostBasesWindow.Avalonia.cs):
  - выбор дисков/корней флажками + «Отметить все / Снять все»;
  - кнопка «Найти базы» (фон, UI не блокируется) и «Прекратить» через `CancellationToken`;
  - таблица найденных баз: Название, Путь к файлу базы, Размер, Дата последнего изменения, «В приложении», «В ibases.v8i»;
  - кнопка «Добавить в список баз» добавляет отмеченные отсутствующие в приложении базы в список баз приложения (новая база появляется в дереве; в ibases.v8i экспортируется только при включённом режиме экспорта — существующая логика `MainViewModel`).
- **Точка входа** — кнопка «Поиск потерянных и забытых баз 1С на дисках» рядом с «Определить\обновить конфигурации всех баз» в Настройки → Базы → Список информационных баз (обе платформы); после закрытия при изменении данных список персистится (`PersistInfobasesAfterInlineEdit` для Windows, публичный метод добавления + персист в `MainViewModel.Avalonia.cs`).
- **Признаки**: «В приложении» — путь есть среди файловых баз приложения (`InfobaseMaintenanceService.GetFileBaseDirectory`); «В ibases.v8i» — база зарегистрирована в реестре 1С (`IbasesV8iImporter.FindDefaultPath()` + чтение записей), сравнение по нормализованному пути.
- **Локализация** новых ключей `Settings.Bases.FindLostBases.*` и `FindLostBases.*` в `ru.json` / `en.json`.

Реализовано в общей кодовой базе и проверено обеими сборками — Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) — без ошибок.
