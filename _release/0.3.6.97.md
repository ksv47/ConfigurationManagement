# 0.3.6.97

Исправление семи issues #216, #215, #214, #201, #174, #165, #153: центрирование текста в поле «Размер» шрифта, сортировка колонок в окне «Очистка кэша», устранение регрессии горизонтального выравнивания компактного режима, сохранение режима запуска по умолчанию при редактировании базы, логирование маскированной строки подключения при ошибке чтения через COM, дедупликация вложенных папок при импорте v8i/StartManager и диагностика этапов запуска на Linux.

## Исправлено

- **Центрирование текста в поле «Размер» шрифта** (#216): текст в поле размера шрифта теперь отцентрован. Файлы: `Views/SettingsWindow.xaml`, `Views/SettingsWindow.Avalonia.cs`.
- **Сортировка колонок в окне «Очистка кэша»** (#215): добавлена сортировка колонок в окне очистки кэша. Файлы: `Views/CacheCleanWindow.xaml.cs`, `Views/CacheCleanWindow.Avalonia.cs`.
- **Компактный режим: устранена регрессия горизонтального выравнивания** (#214): исправлена регрессия горизонтального выравнивания компактного режима в `Themes/ThemeManager.cs`.
- **Пара пожеланий: сохранение режима запуска по умолчанию при редактировании базы** (#201): исправлено сохранение режима запуска по умолчанию при редактировании базы. Файлы: `ViewModels/MainViewModel.Commands.cs`, `ViewModels/MainViewModel.Avalonia.cs`.
- **Кнопка определения свойств конфигурации: логирование строки подключения** (#174): добавлено логирование строки подключения (маскированной от паролей) при ошибке чтения через COM в `Services/OneCComConnector.cs`.
- **Дублирует папки в родном стартере** (#165): добавлена дедупликация вложенных папок при импорте v8i/StartManager в `Services/IbasesV8iImporter.cs`.
- **Linux висит при запуске: диагностика этапов запуска** (#153): добавлена диагностика этапов запуска на Linux (`#if LINUX`) в `App.axaml.cs`.
