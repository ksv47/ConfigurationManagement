# 0.3.7.25

Выпуск реализует issue #236: в настройках (вкладка «Базы» → блок «Экспорт / загрузка списка баз») добавлена кнопка «Определить\обновить конфигурации всех баз» — диалог, который определяет имя конфигурации и номер релиза сразу для нескольких баз.

## Добавлено

- **Диалог «Определение конфигураций всех баз»** ([#236](https://github.com/sivatorov/ConfigurationManagement/issues/236)):
  - таблица со столбцами: флажок выбора, имя базы, текущая конфигурация, номер релиза; в заголовке колонки флажка выводится счётчик отмеченных элементов («Выбрано: N»);
  - базы, у которых уже заполнены и имя конфигурации, и номер релиза, автоматически не отмечаются; незаполненные базы помечаются флажком;
  - кнопки установки, снятия и инверсии отметок;
  - кнопка «Определить» последовательно определяет свойства выбранных баз через COM-чтение (Windows) / конфигуратор или эвристику по `1Cv8.1CD` (Linux), предварительно снимая кэш-вердикт недоступности COM;
  - после успеха флажок строки снимается автоматически; при ошибке флажок остаётся, а в строке показывается текст ошибки;
  - окно не закрывается автоматически, пока остался хотя бы один отмеченный элемент; при закрытии с оставшимися флажками спрашивается подтверждение;
  - правки вносятся напрямую в объекты `Infobase` и сохраняются после закрытия диалога.

Реализовано на обеих платформах — Windows/WPF (`Views/DetectConfigurationsWindow.xaml` + `.xaml.cs`) и Linux/Avalonia (`Views/DetectConfigurationsWindow.Avalonia.cs`). Общая модель строки — `ViewModels/DetectConfigRowViewModel`.

Проверено обеими сборками — Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) — без ошибок.
