# 0.3.6.75

Выпуск с исправлениями issue #153 «Linux — висит при запуске», #178 «Окно "Очистка кэша 1С"» и #180 «Группа не сворачивается, если внутри неё выделена база».

## Исправлено

- **Зависание при запуске на Linux (issue #153)**: `OpaqueWindow` и `DisableAnimations` переведены на вычисляемые свойства с учётом `Virtualized`, `SoftwareRender` и `NoCompositorAssumed`, чтобы автоопределение VM/композитора влияло на непрозрачность окна. Детектор драйверов (`ReadDriGpuDrivers`) теперь читает `/sys/class/drm/card*/device/uevent`, где реально лежит `DRIVER=`, поэтому qxl/vmwgfx/virtio_gpu/bochs/vboxvideo/qemu распознаются корректно.
- **Окно «Очистка кэша 1С» (issue #178)**: на Linux корень `~/.1cv8/1C/1cv8` включается в скан остатков, но каталог считается остатком только при наличии в `IdConnStrMap` и несовпадении строки соединения ни с одной базой. Каталоги `*.deleting_*` находятся и чистятся; размер «остатков» считается по выбранным галкам; в отчёт добавлен объём; подпись «Остатки от удалённых баз <размер>» не обрезается; слово унифицировано на «кэш».
- **Группа не сворачивается (issue #180)**: раскрытие ветки при восстановлении выделения установлено на модель вместо локального значения `IsExpanded` на контейнере (WPF). Двойной клик по служебным узлам «Закреплённые»/«Без группы» корректно переключает состояние модели, не оставляя локального значения в контейнере.
