# 0.3.7.26

Выпуск исправляет issue #245: при автоматическом выборе клиента всегда стартовал толстый клиент (`1cv8.exe`), из-за чего пользователь видел странные ошибки в конфигурациях и долгий запуск.

## Исправлено

- **Приоритет тонкому клиенту при авто-выборе** ([#245](https://github.com/sivatorov/ConfigurationManagement/issues/245)):
  - при режиме запуска базы «Автоматический» без явного указания типа клиента приоритет теперь отдаётся тонкому клиенту `1cv8c.exe`, если он установлен;
  - толстый клиент `1cv8.exe` используется только как запасной (например, если тонкий клиент не установлен);
  - явный выбор «Толстый клиент» / «Толстый клиент (обычные формы)» по-прежнему запускает толстый клиент.

Реализовано на обеих платформах — Windows/WPF ([`Services/OneCLauncher.cs`](Configuration%20Management/Services/OneCLauncher.cs)) и Linux/Avalonia ([`Services/OneCLauncher.Linux.cs`](Configuration%20Management/Services/OneCLauncher.Linux.cs)).

Проверено обеими сборками — Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) — без ошибок.
