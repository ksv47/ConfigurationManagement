# 0.3.7.28

Выпуск исправляет issue #240 «Цвет для группы (Без групп) нельзя изменить»: само исправление цвета служебных узлов было сделано ранее, а в этом выпуске закрывается замечание о том, что в диалоге служебного узла вкладка «Основные» показывала поля, изменения в которых при сохранении не применялись.

## Исправлено

- **Вкладка «Основные» скрыта для служебных узлов «Без группы» и «Закреплённые»** ([#240](https://github.com/sivatorov/ConfigurationManagement/issues/240)):
  - поля «Наименование», «Родительская группа» и «Описание» для служебных узлов при сохранении не применяются, поэтому доступ к ним только вводил пользователя в заблуждение — он мог переименовать «Без группы» или назначить родителя и не увидеть изменений;
  - теперь для служебного узла открывается диалог только с вкладками «Цвет» и «Иконка» (оформление), а вкладка «Основные» не показывается вовсе;
  - реализовано на обеих платформах: Windows/WPF ([`Views/GroupEditWindow.xaml.cs`](Configuration%20Management/Views/GroupEditWindow.xaml.cs)) скрывает вкладку через `Visibility.Collapsed`, Linux/Avalonia ([`Views/GroupEditWindow.Avalonia.cs`](Configuration%20Management/Views/GroupEditWindow.Avalonia.cs)) не добавляет её в набор вкладок для служебного режима.

Реализовано в общей кодовой базе и проверено обеими сборками — Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) — без ошибок.
