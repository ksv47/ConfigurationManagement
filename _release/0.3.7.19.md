# 0.3.7.19

Выпуск добавляет определение и обновление конфигураций всех баз одним прогоном (issue #236): новая кнопка в настройках открывает диалог с таблицей баз, флажками и кнопкой «Определить», которая последовательно определяет имя конфигурации и номер релиза выбранных баз через COM-коннектор.

## Добавлено

- **Определение/обновление конфигураций всех баз** ([#236](https://github.com/sivatorov/ConfigurationManagement/issues/236)) — в «Настройки → Базы → Список информационных баз» рядом с импортом из ibases.v8i добавлена кнопка «Определить\обновить конфигурации всех баз». Открывается диалог `Views/DetectConfigurationsWindow` с таблицей и колонками «флажок», «имя базы», «текущая конфигурация», «номер релиза». В заголовке колонки-флажка — счётчик отмеченных элементов; есть кнопки «Отметить все», «Снять все», «Инвертировать».

- **Автоотметка незаполненных баз** — если у базы уже заполнены и имя конфигурации, и номер релиза, флажок не проставляется автоматически; если хотя бы одно свойство пустое — флажок ставится (это целевые базы для определения).

- **Последовательное определение** — по кнопке «Определить» для выбранных баз последовательно (по одному COM-коннектору через `ConfigurationInfoService.ReadAndApply`, сериализация `ComReadHost`) определяются имя конфигурации и номер релиза. При успехе флажок снимается, при ошибке остаётся видимой в строке. Окно не закрывается автоматически, пока остались отмеченные строки.

- Реализовано для обеих платформ: Windows/WPF (`DetectConfigurationsWindow.xaml`) и Linux/Avalonia (`DetectConfigurationsWindow.Avalonia.cs`); добавлены ключи локализации `DetectConfigs.*` и `Settings.Bases.DetectAllConfigs*` (ru/en).
