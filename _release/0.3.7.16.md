# 0.3.7.16

Выпуск дорабатывает поддержку шаблона имени COM-коннектора (issue #175): имя из шаблона теперь используется при подключении через КОМ+, а в журнал пишутся кандидаты и фактически используемый коннектор.

## Исправлено

- **Имя COM-коннектора из шаблона используется при подключении и логируется** ([#175](https://github.com/sivatorov/ConfigurationManagement/issues/175)) — быстрый отказ по «кэшу доступности» (проверяющему только стандартные имена `V82/V83/V85.COMConnector`) больше не блокирует работу при заданном непустом шаблоне: даже если версию платформы развернуть не удалось, программа доходит до перебора кандидатов (имя из шаблона + стандартный список). В журнал пишутся «Кандидаты COM-коннекторов (в порядке перебора)» и «Использованный COM-коннектор» — как при успехе, так и при ошибке. Путь со стандартными именами при пустом шаблоне не изменился.
