# 0.3.6.79

Технический микровыпуск с исправлением UI: устранена вертикальная обрезка текста в поле выбора шаблона даты/времени (формат отметки даты и времени) на вкладке «Базы» окна «Настройки». Правка внесена в обе реализации — Windows/WPF и Linux/Avalonia.

## Исправлено

- **Вертикальная обрезка текста в поле шаблона даты/времени** на вкладке «Базы» окна «Настройки»: строка формата отметки даты и времени обрезалась снизу из-за фиксированной высоты поля.
  - **Windows/WPF** (`Views/SettingsWindow.xaml`): у элемента `ComboBox x:Name="ExportTimestampFormatComboBox"` убрана фиксированная `Height="34"`, вместо неё задано `MinHeight="38"`, добавлены `Padding="10,5"` и `VerticalContentAlignment="Center"`.
  - **Linux/Avalonia** (`Views/SettingsWindow.Avalonia.cs`): `AutoCompleteBox timestampBox` получил `MinHeight = 38`, а внутренний редактируемый `TextBox` — локальный стиль с `VerticalContentAlignment = VerticalAlignment.Center` и `Padding = new Thickness(6, 4)`.

- `ConfigurationManagement.exe` — Windows x64 (single-file)
- `ConfigurationManagement` — Linux x64 (single-file)
