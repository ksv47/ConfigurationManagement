# Управление конфигурациями 1С

![Версия](https://img.shields.io/badge/Версия-0.2.6.6-1F6FEB) ![.NET](https://img.shields.io/badge/.NET-10-512BD4) ![WPF](https://img.shields.io/badge/WPF-4B8BBE) ![Лицензия](https://img.shields.io/badge/Лицензия-Open%20Source-success)

> Десктопное приложение для управления информационными базами 1С:Предприятие 8.3. **Версия 0.2.6.6**

**Управление конфигурациями 1С** — это настольное приложение на платформе **.NET (WPF)**, которое заменяет стандартный список баз 1С и предоставляет современный интерфейс для работы с информационными базами: запуск в режимах «1С:Предприятие» и «Конфигуратор», вкладки **Все базы / Избранное / Недавние**, иерархические группы, избранное с `Alt+1…9`, мультифильтр по тегам, очистка кеша, синхронизация с `ibases.v8i`, системный трей, светлая и тёмная темы.

## ✨ Возможности

### 🚀 Запуск информационных баз
- Запуск базы в режиме **«1С:Предприятие»** и **«Конфигуратор»**.
- **Настраиваемые горячие клавиши** (Настройки → Клавиши): 1С:Предприятие, Конфигуратор, Избранное, Изменить, Удалить, Очистить кэш, Добавить базу, Закрепить (по умолчанию `F3` / `F4`; поддерживаются F2–F12, Delete, Insert, Ctrl/Shift-комбинации). Отображаются на кнопках правой панели и в контекстном меню.
- **`Ctrl+F`** — фокус в поле поиска (с выделением текущего текста) из любого места главного окна.
- **Горячие клавиши избранного** — `Alt+1`…`Alt+9`: при добавлении в избранное назначается свободный слот; порядок слотов настраивается в окне настроек.
- Выбор типа клиента: **тонкий** / **толстый**, режим **веб-клиента**.
- **Разрядность запуска** по документации 1С — 4 режима: приоритет 32 (x86) / приоритет 64 (x86-64) / только 32 / только 64; при приоритетных режимах лаунчер выбирает более новую установленную версию между 32/64.
- Автопоиск установленной платформы 1С (лаунчер `1CEStart.exe` или `1cv8.exe` / `1cv8c.exe`).
- Запуск **конкретной версии** платформы, заданной для базы.
- **«Перейти по ссылке»** в правой панели — аналог одноимённой функции стандартного загрузчика 1С: вставьте ссылку на базу (`e1c://...`, `C:\1C\База`, `server\База`, `http://server/base`) и запустите её в «1С:Предприятие».
- **Конфигуратор параметров запуска** — визуальный выбор ключей командной строки (`/UC`, `/DisableStartupMessages`, `/Debug` и др.).

### 🗂️ Управление списком баз
- **Вкладки фильтра**: **Все базы**, **Избранное**, **Недавние** (по дате последнего запуска).
- Иерархический список с группами, закреплёнными базами и узлом «Без группы».
- Колонки: наименование, версия платформы, режим запуска, сервер/база, последний запуск, размер; видимость колонок настраивается, **ширину любой колонки можно изменять** перетаскиванием разделителя на её правой границе (данные и заголовок двигаются синхронно).
- **Сортировка по клику** на заголовки колонок (название, дата и др.).
- Добавление, редактирование и удаление баз; мастер «Что добавить?» (база или группа).
- **Избранное** (★) и **закрепление** (📌); закреплённые — в отдельной группе сверху.
- **Поиск** по имени, описанию, группе, версии и тегам (с debounce, без «тормозов» на каждый символ).
- **Теги**: инлайн-добавление в строке базы, компактные чипы, удаление крестиком, **мультифильтр** (несколько тегов сразу) и облако тегов на панели отбора.
- Перетаскивание баз и групп; сворачивание/разворачивание всех групп с верхней панели.
- **Значок тега** в строке заголовка списка (слева от колонки «Название») включает/выключает **только теги в строках списка баз** и не затрагивает панель быстрого отбора тегов. **Верхняя кнопка «Показывать теги»** на верхней панели включает/выключает и **панель тегов сверху** (облако тегов), и **теги в списке баз**; её состояние отражает видимость панели тегов сверху и остаётся включённой, пока панель тегов отображается. Панель также управляется настройкой в окне настроек.
- **Навигация стрелками** по списку: `↑`/`↓` — переход по строкам (базам и группам), `←`/`→` — сворачивание/разворачивание выбранной группы. Стрелки всегда управляют выделением в дереве и не перескакивают на кнопки внутри строки.

### 🏷️ Группы
- Вложенные группы («группа в группе») с **наглядным смещением** заголовков групп по глубине вложенности — всегда видно, какая группа находится внутри другой, а также цвет и **иконка** группы.
- В правой панели при выборе группы отображается **выбранная иконка**.
- Создание, редактирование, удаление; выбор родителя в дереве групп.

### 🔄 Импорт, экспорт и синхронизация
- Импорт / экспорт **`ibases.v8i`** (в т.ч. кнопки на главном окне).
- **Синхронизация** с `ibases.v8i`: отключена / только загрузка / только выгрузка / двусторонняя; триггеры — при старте, по интервалу, по расписанию.
- Экспорт / импорт списка в **JSON**; очистка всего списка с подтверждением.
- Автосопоставление **ID (GUID)** базы из `ibases.v8i` для точечной очистки кеша.
- **Резервные копии `ibases.v8i`** перед синхронизацией/экспортом (`ibases.v8i.bak_yyyyMMdd_HHmmss`), хранение N последних копий, кнопка «Восстановить из последней копии» в настройках синхронизации.

### 🧹 Очистка кеша 1С
- Очистка локального кеша платформы для выбранной базы по GUID.

### 🛠️ Создание информационных баз
- Создание ИБ через `CREATEINFOBASE`: пустая база или **из шаблона** (.cf / .dt), файловая и клиент-серверная.
- **Шаблоны конфигураций** — список установленных конфигураций из стандартных каталогов `tmplts` (разбор `1cv8.mft`, как в стартере 1С), группировка в дереве, либо выбор файла вручную.
- **Настройка каталогов шаблонов** в Настройки → Базы (приоритет пути из настроек стартера 1С), кнопка «Из 1С».

### 📦 Обслуживание баз
- **История запусков** (до 30 записей на базу) — пополняется при запуске/выгрузке/тесте, просмотр из контекстного меню.
- **Выгрузка `.dt` / `.cf`** и **тестирование ИБ** (`/IBCheckAndRepair -TestOnly`) через пакетный `DESIGNER`.
- **Открыть каталог** файловой базы в проводнике; **ярлык на рабочем столе** (как у стандартного стартера 1С).
- **Удалить отсутствующие файловые базы** (нет каталога / `1Cv8.1CD`) и **завершить процессы 1С** (1cv8, 1cv8c и др.) — Настройки → Базы → Обслуживание.
- Колонка **«Размер»** для файловых ИБ (видимость настраивается в Отображение → Колонки).
- **Удаление ИБ** с опцией **«Физически удалить каталог базы с диска»** (только файловые, с повторным подтверждением).

### 🪟 Системный трей и поведение
- Значок в трее, **закрытие в трей**, восстановление окна двойным кликом.
- Запрет второго экземпляра (опционально) с активацией уже открытого окна.
- Контекстное меню трея: **недавние базы** (до 7) с подменю «1С:Предприятие / Конфигуратор», синхронизация ibases, настройки, выход.
- **Esc → в трей** (настройка «По Esc сворачивать в трей»).
- Кнопка **«Выход»** в правой панели главного окна (в самом низу) **всегда полностью завершает работу приложения**, игнорируя настройку «Закрывать в трей» — в отличие от закрытия окна крестиком, которое при включённой опции сворачивает программу в трей.

### ⚙️ Настройки приложения
- Вкладки: **Платформы**, **Отображение**, **Клавиши**, **Настройки**, **ibases.v8i**, **Базы**, **О программе**.
- Вкладка «Отображение»: подвкладки (Значки и кнопки, Колонки списка, Панели, Нижняя панель) с тумблерами видимости элементов.
- Вкладка «Клавиши»: горячие клавиши запуска и порядок избранного `Alt+1…9`.
- Вкладка «Настройки»: поведение приложения (несколько экземпляров, значок в трее, сворачивание, `Esc` → трей).
- Вкладка «Платформы»: группировка по линии **8.3 / 8.5** и **разрядности** (64/32) с путями установки, **дополнительные пути поиска** платформы.
- Вкладка «Базы»: каталоги шаблонов, экспорт/загрузка списка баз, обслуживание (удаление отсутствующих баз, завершение процессов 1С).
- Вкладка «О программе»: автор, Infostart, GitHub.
- Кнопки **Сохранить** (зелёная) и **Отмена** (красная обводка) — единый стиль диалогов.
- Окно **настроек подключения к базе** оформлено в том же стиле (шапка, те же кнопки) с **вертикальными вкладками слева** — **База / Подключение / Аутентификация / Запуск / Разрядность / Платформа / Идентификатор**; каждая вкладка содержит один логический блок без прокрутки. Поле **«Сервер»** на вкладке «Подключение» — выпадающий список с серверами 1С из других клиент-серверных баз списка (можно выбрать или ввести вручную). Поле **«Порт сервера»** — такой же **редактируемый выпадающий список** с портами из существующих клиент-серверных баз (без дублей, по возрастанию): удобно, когда сервер один, а инстансы висят на разных портах.
- **«Вставить строку подключения»** — кнопка **слева внизу** окна настроек базы (доступна на **любой вкладке** и при создании новой базы, и при правке свойств). По клику открывается **окно ввода строки подключения** с полем для ввода и кнопкой **«Вставить из буфера»**; если в буфере обмена лежит строка, удовлетворяющая критериям ссылки на базу 1С (строка подключения с `Srvr`/`Ref`/`File`/`WS`, ссылка-протокол `e1c://`, веб-адрес `http(s)://`, путь к файловой базе или `server\base`), она **автоматически подставляется** в поле. Кнопка **«Применить»** разбивает строку по полям — тип подключения, сервер/порт, имя базы, путь файла или URL веб-публикации, пользователь и пароль. Если наименование базы не задано, подставляется имя базы (`Ref`) или каталога файловой базы. При открытии свойств существующей базы поле заполняется её текущей строкой подключения.

### 🎨 Интерфейс
- **Светлая** и **тёмная** темы; переключение с главного окна.
- Верхняя панель в один ряд: группировка / развернуть / свернуть · поиск с чипами тегов · вкладки списка · синхронизация ibases · тема · настройки.
- **Правая панель**: карточка базы или группы, действия запуска с отображением хоткеев, изменение, избранное, закрепление, очистка кеша, удаление. Блок **«Текущая сессия»** — режим клиента и разрядность без изменения настроек базы.
- **Компактный режим** правой панели — только кнопки действий (ширина по содержимому).
- **Нижняя панель** (статус): путь/сервер, порт, платформа, разрядность, режим запуска, тип клиента, тип подключения, пользователь, ID базы (настройка видимости).
- Современные стили кнопок, ComboBox, GroupBox; виртуализация списка для больших каталогов баз.
- Сохранение размеров окна, темы, свёрнутых групп и настроек отображения между запусками.

### ⚡ Производительность
- Перестройка дерева только при необходимости; добавление/удаление тега без полной пересборки UI.
- Отложенное сохранение на диск; debounce поиска.
- Фильтрация тегов через `HashSet`; обновление облака тегов только при реальном изменении набора.

## 🔧 Сборка и запуск

### Из исходного кода

```bash
# Клонирование репозитория
git clone https://github.com/USERNAME/Configuration-Management.git
cd Configuration-Management

# Сборка проекта
dotnet build "Configuration Management/Configuration Management.csproj"

# Запуск
dotnet run --project "Configuration Management/Configuration Management.csproj"
```

Либо откройте файл решения `Configuration Management.slnx` в **Visual Studio 2022+** и запустите проект.

### 📦 Публикация автономного приложения

Проект настроен на публикацию в виде **автономного (self-contained) single-file** исполняемого файла для Windows x64. Для публикации выполните:

```bash
dotnet publish "Configuration Management/Configuration Management.csproj" -c Release
```

Результат появится в каталоге `publish/` — один исполняемый файл `Configuration Management.exe`, который не требует установки .NET Runtime на целевой машине.

## 🔗 Работа с файлом `ibases.v8i`

Приложение взаимодействует со стандартным файлом списка баз 1С `ibases.v8i` (расположен в `%APPDATA%\1C\1CEStart\`):

- **Импорт** — считывает базы, группы, ID (GUID), версию платформы (`Version`), режим запуска (`App`), локаль (`Locale`), признак внешней базы (`External`), скорость соединения (`ClientConnectionSpeed`), признак веб-клиента (`WA`) и дополнительные параметры подключения (`AdditionalParameters`, сохраняются в параметры запуска базы). Поддерживает **иерархию групп**: пути вида «Родитель\Дочерняя» разбираются на сегменты, недостающие родительские группы создаются автоматически. Добавляет новые базы и обновляет существующие.
- **Экспорт** — выгружает базы и группы приложения в файл `ibases.v8i`, добавляя новые записи и обновляя существующие (по совпадению имени базы). Группы записываются секциями без строки подключения, для баз переносятся версия платформы, режим запуска (`App`/`DefaultApp`) и дополнительные параметры запуска. Существующие секции-группы только обновляются (новые при выгрузке не создаются), а дубликаты секций с одинаковым именем устраняются (приоритет — за базой).
- **Синхронизация** — в окне настроек можно задать режим автоматической синхронизации с файлом `ibases.v8i` (отключена / только загрузка / только выгрузка / двусторонняя) и путь к файлу. Синхронизация выполняется автоматически при изменении списка баз, при запуске приложения, через заданный интервал или по расписанию, а также вручную по кнопкам «Загрузить» / «Выгрузить».
- **Сопоставление ID** — при ручном создании базы приложение автоматически находит её ID в `ibases.v8i` по имени или строке подключения и подставляет его. Это обеспечивает корректную точечную очистку кеша 1С по GUID.
- **Очистка кеша** — использует ID базы (GUID) для удаления только соответствующего подкаталога кеша, а не всего каталога базы.

## 🧩 Архитектура

Приложение построено по паттерну **MVVM**:

- **Models** — описывают доменные сущности (информационные базы, группы, настройки подключения).
- **ViewModels** — содержат логику представления и команды, реализуют `INotifyPropertyChanged`.
- **Views (XAML)** — отвечают за отображение и привязку данных.
- **Services** — инкапсулируют работу с платформой 1С, файловой системой и хранилищем данных.

## Сборка

### Локально (Windows)

```powershell
# Только сборка
.\build.ps1

# Сборка + публикация single-file win-x64
.\build.ps1 -Publish
```

Результат публикации: `publish\win-x64\`.

Или вручную:

```powershell
dotnet build "Configuration Management.csproj" -c Release
dotnet publish "Configuration Management.csproj" -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\publish\win-x64
```

> На Linux/macOS сборка не поддерживается (проект WPF `net10.0-windows`). Для публикации используйте Windows или GitHub Actions (`.github/workflows/`).

### Автоматическая сборка (GitHub Actions)

| Workflow | Когда запускается | Что делает |
|----------|-------------------|------------|
| **Build** (`.github/workflows/build.yml`) | push / PR в `main`, `master`, `develop` | Restore → Build Debug/Release → Publish win-x64 → artifact |
| **Release** (`.github/workflows/release.yml`) | тег `v*.*.*` или ручной запуск | Publish + ZIP + GitHub Release |

Создание релиза:

```bash
git tag v0.2.5.83
git push origin v0.2.5.83
```

Артефакт `ConfigurationManagement-v0.2.5.83-win-x64.zip` появится в Releases.

> Требуется Windows-раннер (`windows-latest`): проект WPF (`net10.0-windows`).
